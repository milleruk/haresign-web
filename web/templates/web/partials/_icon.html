{% comment %}Inline SVG icon. {% include 'web/partials/_icon.html' with name='arrow-right' %} **Solid, not outline.** An earlier version used 2px-stroke outline geometry and read as thin and weak inside the 54px tinted chips — noticeably lighter than the icon font the previous design used. These are filled shapes, which carry the same visual weight without the font dependency: the whole set is one HTTP request that is already part of the HTML. Inline rather than an icon font: a font is a render-blocking request, and every icon here is decorative beside a text label, so it must be aria-hidden and contribute nothing to the accessible name. `currentColor` means an icon always matches the text beside it with no per-context rule. The svg fills by default; the few elements that want a line set their own stroke. {% endcomment %}
